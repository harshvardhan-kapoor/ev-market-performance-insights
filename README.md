
# ⚡ Electric Vehicle Market Performance & Insights

An interactive data visualization project exploring the electric vehicle market using Tableau Public, Python, Flask, HTML, and CSS.

## Overview
This project presents an interactive Tableau story embedded in a custom-designed Flask website. It provides a user-friendly way to explore EV market data and the visualizations created for the project.

## Features
- Interactive Tableau Public story
- EV market visualization and analysis
- Responsive dark-themed website
- Flask-based web application
- HTML and CSS styling

## Technologies Used
- Python
- Flask
- Tableau Public
- HTML5
- CSS3
- Git and GitHub

## Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/harshvardhan-kapoor/ev-market-performance-insights.git
   ```

2. Open the project folder:
   ```bash
   cd ev-market-performance-insights
   ```

3. Install Flask:
   ```bash
   python -m pip install flask
   ```

4. Start the application:
   ```bash
   python app.py
   ```

5. Open http://127.0.0.1:5000 in your browser.
